Relatórios para impressão

Os relatórios utilizam os dados dos cadastros, seguem a ordem institucional dos setores e organizam os nomes alfabeticamente dentro de cada setor. Cadastros inativos ficam de fora por padrão. Use Campos do relatório para escolher as informações e Setores exibidos para definir quais grupos entrarão na relação.

Dados e backup da unidade

Verificando sincronização...
Os dados desta unidade são salvos no banco online. O navegador mantém uma cópia local de contingência, mas o banco em nuvem é a fonte principal.
A exclusão esvazia somente a unidade selecionada e exige confirmação explícita.

Backup geral do sistema

Exclusivo do Administrador Geral.
Inclui todas as escolas, seus dados, usuários e vínculos. Senhas nunca entram no arquivo e os logins existentes não são sobrescritos durante a restauração.
Antes de restaurar, o sistema baixa automaticamente uma cópia do estado atual. A restauração substitui escolas, dados e vínculos pelo conteúdo do arquivo e exige a confirmação RESTAURAR SISTEMA.

Administração central

Área exclusiva do Administrador Geral. Cadastre escolas, crie usuários, defina permissões e visualize o sistema como outro usuário em modo somente leitura.
